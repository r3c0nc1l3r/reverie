# Smoke lab — support

## Goal

Confirm that a support user can identify a hard-to-see control and use the visible archive fallback.

## Fixtures

Use only the local smoke lab. No login, external account, or remote service is involved.

## Steps

1. Inspect the tiny low contrast target before activating it.
2. Activate the tiny target and verify the visible result.
3. Inspect the permanently missing archive icon and record the visual failure.
4. Use the visible text fallback and verify the archive result.

## Evidence

Keep native observation frames and target crops for the tiny target and broken archive icon.

## Guidance

Do not claim semantic accuracy from this fixture. It tests execution guards and evidence handling only.
