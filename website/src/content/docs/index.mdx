## How it works

<CardGrid>
	<Card title="Laya (local)" icon="laptop">
		A small local model served by laya.cpp makes each click and keystroke from the elements it
		observes on the page.
	</Card>
	<Card title="Pilot (multimodal)" icon="rocket">
		A multimodal model runs the spec: it sends intents, checks results, marks steps, records
		findings, reviews screenshots, and speaks short progress updates.
	</Card>
	<Card title="Orchestrator (you or an agent)" icon="seti:shell">
		Starts sessions and specs, signs in, handles checkpoints such as database or mail proof, and
		reviews the verdicts.
	</Card>
	<Card title="Guards" icon="approve-check">
		Commit buttons such as Save or Delete need an explicit intent, only stated values are typed,
		and loops or stalls end in a checkpoint. Tokens and codes are masked.
	</Card>
</CardGrid>

## Try it

```bash
uv run reverie --session demo start --url https://the-internet.herokuapp.com/
uv run reverie --session demo spec examples/specs/demo-controls.md
uv run reverie --session demo pilot
uv run reverie ui      # dashboard at http://127.0.0.1:7788/
```

See [Your first run](/reverie/start/first-run/) for the full walkthrough.

## Review every run

The dashboard shows suites, tests and runs, the frame for each event, and the event timeline.
Replays turn a run into slides with step verdicts and the pilot's narration.

![Run dashboard with the timeline and a frame](../../assets/dashboard.png)
